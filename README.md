# Skybarrel Investment Database Operations (SQL)

This project demonstrates SQL Data Manipulation Language (DML) operations performed on the Skybarrel investment database. The objective of the project was to manage and analyze financial investment data through structured SQL queries.

## Project Overview
The database contains information related to investments, portfolios, and financial transactions. SQL queries were written to manipulate and retrieve meaningful data insights that support investment analysis and decision-making.

## Key SQL Concepts Used
- INSERT, UPDATE, and DELETE statements
- Data filtering using WHERE conditions
- JOIN operations to combine related tables
- Aggregation functions such as SUM, COUNT, and AVG
- GROUP BY and ORDER BY for structured analysis

## Skills Demonstrated
- SQL Data Manipulation (DML)
- Financial data analysis
- Relational database querying
- Data aggregation and filtering

## Project Outcome
The queries developed in this project enable efficient management of investment records and extraction of useful financial insights. This demonstrates the practical use of SQL in analyzing structured financial datasets and supporting data-driven investment decisions.

## Stakeholder Feedback
Stakeholders highlighted that the SQL queries significantly improved the accessibility of investment data and simplified reporting processes. The structured queries enabled faster retrieval of portfolio metrics, transaction summaries, and performance indicators, allowing teams to gain clearer insights into investment trends and make more informed financial decisions.
